# M04｜烹饪痛点研发实验室

## 目标
把“做饭麻烦”转化为可体验的研发项目，是主线最有趣的支线，也是让玩家理解公司不只会拼菜谱的关键模块。

## 解锁与流程
菜单草案完成后，Pulse 推荐一个与玩家目标匹配的项目：少洗锅→ZeroWash/OnePot；15 分钟→Speedrun；清冰箱→Leftover；翻车担忧→Failure。玩家只需选择一次实验路线，成果会写入结果卡。

## 角色与项目

| 角色 | 项目 | 电脑互动 | 结果影响 |
|---|---|---|---|
| ZeroWash | Project Zero Wash | 选择锅底风味复用/隔离烹饪 | 减少锅具与清洗说明 |
| OnePot | Project One Pan | 选择一锅串行/蒸炒分层 | 修改时间线 |
| Speedrun | Project 15:00 | 选择省步骤/保口感 | 修改菜数和准备方式 |
| Leftover | Fridge Rescue | 选择优先消耗项 | 修改食材利用率 |
| Failure | Kitchen Rescue | 选择最担忧翻车点 | 增加补救提示 |
| Smoke/Cleanup | Silent Kitchen | 选择低油烟/少收拾 | 修改烹饪技巧标签 |

## 场景与幽默边界
透明实验厨房、洗锅计数器、机器人锅铲和失败样本柜构成原创荒诞实验室。幽默针对流程和设备，不嘲笑用户、不虚构食品安全能力；“实验成功”只表示活动模板已选择，不代表科学验证。

## 工作台模板
`痛点 → 实验假设 → 两条可选路线 → 对本局菜单的影响 → 已知限制 → 交给厨房团队的执行说明`。

## 验收
- 至少一项研发选择改变锅具数、步骤或提示；
- 所有项目均能回到主线，不形成死路；
- 不以“完全不洗锅”诱导不卫生做法，显示必要清洁条件；
- 玩家能在结果卡看见采用的研发方案。
