# M05｜预制菜研发与工厂

## 目标
以模拟流水线展示“菜谱知识如何被规模化产品化”，补足产业链叙事；它是主线完成后的探索区，不能被理解为真实工厂、食品销售承诺或实际生产数据。

## 参观路径

```text
原料收货 → 清洗分拣 → 切配 → 烹饪 → 急冷/保鲜 → 包装贴标 → 质检 → 冷库 → 发货
```

玩家点选一种示例餐盒，镜头沿流水线移动；每站显示一条“这个步骤解决什么问题”的短解释。

## 岗位
Intake Inspector、Sorting Operator、Batch Planner、Kitchen Line Controller、Quality Gate、Cold Chain Monitor、Dispatch Coordinator、Recall Officer；研发侧另有 ShelfLife、Reheat、Portion、FlavorLock、Pack、TastePanel、Label。

## 关键热点

- **Batch Planner 电脑**：展示模拟工单、产量和排产冲突；
- **Quality Gate 屏幕**：显示合格/待复核/阻断，不展示真实食品检测值；
- **冷库大屏**：解释温度记录、批次和先入先出概念；
- **召回演练按钮**：以无真实品牌的模拟批次，演示从餐盒回溯到原料的路径。

## 主线关联
玩家在结果页可点击“如果这道菜被做成预制餐盒会怎样”，得到：适合/不适合预制的说明、哪些步骤应留给用户、复热时的体验假设。此内容是体验性判断，不能当作商业配方。

## 验收
- 参观不要求玩家学习复杂生产术语；
- 清楚标注模拟数据和演示批次；
- 质量异常会触发阻断/复核，而不是继续流转；
- 不展示可用于识别真实供应商、库存或内部生产信息的数据。
