# M11｜技术、内容配置与运营后台

## 目标
用可版本化的内容和确定性状态机支撑活动游戏；让运营能修改任务、角色、分支、工厂/农田模拟事件和结果模板，而不需要修改场景代码。

## 核心架构

```text
Next.js 应用
├─ PixiJS 场景渲染
├─ React UI / Framer Motion
├─ Session State（Zustand/XState）
├─ Content Resolver（任务模板与分支）
└─ API（分享、可选个性化、匿名埋点）

内容仓库/CMS
├─ 任务模板
├─ 食材与安全规则
├─ 角色、房间与热点
├─ 对话、决策和结果卡
├─ 模拟事件（工厂/田地/SAP/财务/配送）
└─ 公共内容审核状态
```

## 内容对象

| 对象 | 必填字段 |
|---|---|
| MissionTemplate | 主题、阶段、输入、分支、结果映射、版本、发布状态 |
| AgentProfile | 岗位、房间、状态文案、工作台模板、权限边界 |
| SceneHotspot | 场景、坐标、焦点、解锁条件、替代列表入口 |
| SimulationEvent | 来源模块、可见等级、摘要、状态影响、演示标签 |
| ResultTemplate | 菜单/时间线/安全提醒/分享字段 |
| PublicContent | 来源、审核人、可见性、失效日期、披露文本 |

## 后台能力

1. 创建/发布任务主题与分支；
2. 开关建筑、热点和活动内容；
3. 预览一个会话，导出分支测试矩阵；
4. 审阅公共内容、公益披露与 PR 文案；
5. 查看匿名漏斗：进入、输入完成、决策完成、结果生成、探索模块；
6. 管理资产版本、动画配置和降级开关；
7. 查看错误与性能指标，不查看个人原始输入。

## API 与数据边界

- `POST /session`：创建随机会话，默认只在客户端保存；
- `POST /share`：接受脱敏结果标签，生成短链接；
- `POST /personalize`（可选）：受限 JSON 生成，输入校验、内容审查、失败回退模板；
- `POST /analytics/events`：匿名事件；
- 不提供直接读取真实 SAP、工厂、农田、财务或捐赠系统的公开 API。

## 发布和治理
内容对象有 `draft → review → approved → published → archived` 状态。涉及安全、公益、财务、供应链或公关的公共内容必须指定审阅角色。模拟内容统一携带 `demo=true` 和披露文案，前端不得移除。

## 验收
- 新任务主题不改前端代码即可上线；
- 内容修改能通过版本号追溯；
- 分支覆盖测试能发现不可达/无结果路径；
- 分享、埋点、个性化服务故障都不阻断模板主线；
- 所有公开材料都有来源、可见性和审阅状态。
